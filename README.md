# PAC 3. Tutorial d'A-FRAME 360º
Autor: **Paula Margarit Corominas**

## Descripció
Aquest projecte consisteix en la creació de dues escenes de realitat virtual desenvolupades amb A-Frame, utilitzant continguts panoràmics de 360º creats amb Blender.

## Escenes del projecte
### a-sky
Escena de realitat virtual que representa un bosc, creada a partir d'una imatge panoràmica de 360º mitjançant l'etiqueta <a-sky>. Incorpora un octàedre amb textura i animacions interactives.

### a-videosphere
Escena de realitat virtual que representa un túnel futurista amb llums de neó, creada a partir d'un vídeo panoràmic de 360º mitjançant l'etiqueta <a-videosphere>. Incorpora un con amb textura que es desplaça de manera animada i modifica la seva opacitat quan s'hi interactua.

## Accés al projecte
Les dues escenes es poden explorar des de la pàgina inicial, que incorpora portals per accedir a cadascuna.
